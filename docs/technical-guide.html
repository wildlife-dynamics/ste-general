Technical Guide

A deeper look at how the STE General Workflow is built: the data ingestion pipeline, the methodology behind each map output, and how the final report and dashboard are assembled.

Download the full Technical Guide (PDF) v1.3

Version 1.3 covers the upgrade to ecoscope-platform 2.25.3 (ecoscope-workflows-ext-custom 0.1.4, ecoscope-workflows-ext-ste 0.0.24): all 13 maps are now drawn with the platform's own create_path_layer / create_scatterplot_layer / create_geojson_layer / draw_map and set_base_maps tasks, eight map layers have hover tooltips, the Subject Group Name and Event Types are picked from EarthRanger drop-downs, the base map layers are documented as fixed in the spec, and the previous period defaults to Same as current period. Version 1.2 documented the advanced Include Subject Additional toggle and the bump to ecoscope-platform 2.18.0. Version 1.1 updated the guide for the migration to the ecoscope-platform task/compiler runtime, the restructured Preset / Calendar / Custom previous-period selector, the shared user-configurable raster step length, corrected basemap opacities, and a units fix on the trajectory segment filter table.
